# Feature archives

The feature archives are not regenerated by this repository; they are the
standard utterance-level dumps used by the MELD / IEMOCAP dialogue benchmarks.

* **text** — 1024-d RoBERTa sentence embedding of the utterance transcript.
* **audio** — 300-d (MELD) / 1582-d (IEMOCAP) frame-level acoustic summary.
* **visual** — 342-d facial action unit / expression summary.
* **context** — 1024-d embedding of the preceding utterance plus speaker-tagged
  context, used as the event-stream input.

`merc/data.py` documents every field index it reads from the pickles, so a
re-extracted archive can be dropped in as long as those indices match.
